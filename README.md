# AgriAI – Smart Agriculture Assistant 🌱
**A Frontend Demo Project | Idea by Waseem Anwar**

AgriAI is a responsive Smart Agriculture Assistant website built using **React.js and Vite**. It is designed to help farmers access useful agricultural information and make better farming decisions through technology.

## ⚠️ Important Notice – Demo Website
**This is currently a demonstration website (Frontend Only).**

The website is developed to demonstrate the design, user interface, and proposed features of the AgriAI concept. Some features use sample data or simulated functionality.

It is not yet a fully functional, production-ready agricultural platform. Backend integration, a database, real-time APIs, and AI models will be required to make all features fully operational.

```bash
npm run build

```

## Included Modules

- **Dashboard:** Overview cards, crop disease sample, weather forecast, and market trends.
- **Disease Detection:** Image upload, preview, and simulated disease analysis.
- **Weather Dashboard:** Sample local weather information.
- **Crop Market Prices:** Crop prices with search and category filters.
- **Fertilizer Guide:** Frontend fertilizer recommendations based on crop and soil selection.
- **Consultation Form:** Farmers can submit consultation requests, saved locally in the browser.
- **User Profile:** Profile editing and demo sign-in/sign-out functionality.

## What Can AgriAI Do When Fully Developed?

If AgriAI is developed into a fully functional platform with a backend, database, real AI models, and external APIs, it could provide the following services:

### 1. AI-Based Crop Disease Detection
Farmers could upload pictures of their crops. An AI model could analyze the images, identify possible diseases, and provide treatment suggestions.

### 2. Live Weather Forecast
Farmers could receive real-time weather updates, rainfall predictions, temperature information, and weather alerts to plan their farming activities.

### 3. Live Crop Market Prices
Farmers could check updated market prices of crops in different markets and compare prices to make better selling decisions.

### 4. Smart Fertilizer Recommendations
The system could recommend suitable fertilizers based on crop type, soil information, and nutrient requirements.

### 5. Farmer Consultation
Farmers could contact agricultural experts, submit questions, and receive professional guidance about crop diseases, fertilizers, irrigation, and farming methods.

### 6. User Accounts and Farm Management
Farmers could create accounts, manage their profiles, save crop information, and maintain records of their farming activities.

### 7. Smart Farming Notifications
The platform could send alerts about weather changes, crop diseases, irrigation schedules, and important agricultural updates.

### 8. Support for Local Languages
The platform could support languages such as English, Urdu, and Sindhi to make agricultural information accessible to more farmers.

## Current Project Limitations

This project is currently frontend-only:

- No backend server is connected.
- No MongoDB or other database is integrated.
- No real AI model is connected.
- Weather and crop prices are sample/demo data.
- Disease detection is simulated and does not provide a real diagnosis.
- Consultation requests and profile information are stored in browser LocalStorage.
- Uploaded crop images are previewed in the browser and are not uploaded to a server.
